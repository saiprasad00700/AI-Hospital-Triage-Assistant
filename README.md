# 🏥 AI Hospital Triage Assistant

An NLP-powered hospital triage system that classifies patient symptom descriptions into medical intents using BioClinicalBERT. The project helps hospitals automate the initial triage process and route patients to the appropriate department.

## 🚀 Project Overview

This project uses Natural Language Processing (NLP) and a fine-tuned BioClinicalBERT model to understand free-text symptoms entered by patients and predict their medical intent in real time.

## ✨ Features

- BioClinicalBERT-based intent classification
- Medical text preprocessing
- Symptom-to-intent prediction
- Confidence score generation
- Streamlit web application
- Trained model deployment
